# 🔐 Password Strength Checker

A cybersecurity-focused web application that checks the strength of a password in real-time.

## 🚀 Features
- Real-time password strength analysis
- Visual strength indicator (color-based bar)
- Checks for:
  - Minimum length
  - Uppercase letters
  - Numbers
  - Special characters
- User-friendly dark theme UI

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript

## 🎯 Purpose
This project demonstrates basic cybersecurity practices by helping users create strong and secure passwords.
